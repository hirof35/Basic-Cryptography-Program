# 暗号基礎プログラム（C言語）

シーザー暗号・単一換字式暗号・XOR暗号の暗号化および復号化を対話形式で試せる学習用C言語プログラムです。

## 概要

コマンドライン（CLI）のメニューから暗号方式を選び、平文やキーを入力することで、暗号文と復号文を確認できます。

### 対応している暗号方式

1. **シーザー暗号**
   - アルファベットを指定したシフト数だけずらす換字式暗号です。
   - 大文字・小文字を区別して変換し、英字以外の文字（空白や記号など）はそのまま残します。
2. **単一換字式暗号**
   - 固定の換字表（`A-Z` → `QWERTYUIOPASDFGHJKLZXCVBNM`）に基づいて英字を置換します。
   - 大文字・小文字を維持したまま暗号化・復号化を行います。
3. **XOR暗号**
   - 入力された共通キーとデータの各バイトで排他的論理和（XOR）を取ります。
   - 暗号文は16進数表記（`%02X`）で表示されます。
4. **一括実行（全種類）**
   - 1つの共通平文に対して、シーザー暗号（シフト数: `3`）、単一換字式暗号、XOR暗号（キー: `secret123`）をまとめて実行し、暗号化と復号の結果を表示します。

## ビルドと実行方法

### コンパイル

`gcc` などのCコンパイラでビルドします。

```bash
gcc -Wall -Wextra -o cipher_demo main.c
※ ソースファイル名が main.c 以外の場合は適宜読み替えてください。

実行
Bash
./cipher_demo
使い方
起動するとメニューが表示されます。0〜4 の数字を入力して操作します。

Plaintext
==============================
       暗号基礎メニュー       
==============================
  1. シーザー暗号
  2. 単一換字式暗号
  3. XOR暗号
  4. 一括実行（全種類）
  0. 終了
==============================
1：平文とシフト数（1〜25）を入力して暗号化・復号を実行

2：平文を入力して暗号化・復号を実行

3：平文と共通キーを入力して暗号化（16進表示）・復号を実行

4：共通の平文を入力して3方式を一括テスト

0：プログラムを終了

注意点・制限事項
最大文字数：平文・キー・作業用バッファはそれぞれ最大 1023 文字（終端文字 '\0' を含め MAX_LEN = 1024）まで扱えます。

XOR暗号のキー空文字：共通キーが空文字（""）のまま実行すると keylen が 0 になりゼロ除算（i % keylen）が発生するため、キーは1文字以上入力してください。

負のシフト数：シーザー暗号で負の数を入力した場合、shift % 26 の挙動が処理系依存になる場合があるため、1〜25 の正の整数を入力する想定となっています。

学習用途向け：本コードは暗号の仕組みを学ぶための基礎実装であり、実際のセキュリティ用途（機密通信やパスワード保護など）には使用しないでください。
